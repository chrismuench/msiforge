Why MsiForge?

Pure Managed C#

No WiX required. The entire MSI engine is written in pure managed C#—no native dependencies, no licensing fees, no installed tools needed.

Cross-Platform

Build and sign MSIs on Windows, macOS, and Linux. The same binary works everywhere—no cross-compilation needed.

Intune-Ready

Automatic handling of ProductCode, UpgradeCode, versioning. Your upgrades actually upgrade—no silent failures.

Single Binary

Download one file. Run it. No .NET runtime to install, no MSI installer to run. One file does it all.

Why Not WiX?

WiX ships wixnative.exe for Windows only. It cannot emit an MSI on macOS or Linux because database creation and cabinet compression are delegated to that native helper.

Licensing is another concern—WiX 5.0.2 is the last MS-RL release. 6.0+ moved to a model that bills companies over $10k revenue.

MsiForge solves both: pure managed code, cross-platform, MIT licensed.

Quick Start

1 msiforge # the app
2 msiforge doctor # what can this machine do?
3 msiforge selftest # build and verify a package end to end
4 msiforge build myapp.msiforge # build an MSI
