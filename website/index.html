Why MsiForge?

Most failed Intune upgrades aren't Intune's fault—they're from invisible issues like unchanging ProductCodes or fourth-field version differences. MsiForge owns those values so they can't go wrong.

And no, you don't need WiX. WiX 6+ requires a license fee for companies over $10k revenue. MsiForge is pure managed C#—no native dependencies, no license fees, no installer needed.

Get Started

Download the binary for your platform and run it. The same binary is both the desktop app and the CLI.

Windows macOS Linux ARM64 x64 
msiforge doctor     # what can this machine do?
msiforge selftest   # build and verify a package end to end
msiforge build myapp.msiforge
