Why Not WiX?

WiX ships wixnative.exe for Windows only. It cannot emit an MSI on macOS or Linux. Licensing is another concern—WiX 5.0.2 is the last MS-RL release. 6.0+ moved to a model that bills companies over $10k revenue.

The Solution

MsiForge is pure managed C#—cross-platform, MIT licensed, with no native dependencies or licensing fees. Same binary works on Windows, macOS, and Linux.

Pure Managed C#

No WiX required. The entire MSI engine is written in pure managed C#—no native dependencies, no licensing fees.

Cross-Platform

Build and sign MSIs on Windows, macOS, and Linux. The same binary works everywhere.

Intune-Ready

Automatic handling of ProductCode, UpgradeCode, versioning. Your upgrades actually upgrade.

Single Binary

Download one file. Run it. No .NET runtime to install. One file does it all.

Running on macOS or Linux?

The macOS binary needs to be unquarantined on first run:

1 xattr -d com.apple.quarantine ./MsiForge-macos-arm64
2 chmod +x ./MsiForge-macos-arm64

On Linux, just run:

1 chmod +x ./MsiForge-linux-x64

Quick Start

1 msiforge # the app
2 msiforge doctor # what can this machine do?
3 msiforge selftest # build and verify a package
4 msiforge build myapp.msiforge # build an MSI
